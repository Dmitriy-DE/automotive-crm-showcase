# Operational boundaries

The production system is intentionally not reproduced here.

Publicly safe engineering characteristics:

- containerised services;
- persistent database and media volumes;
- environment-based configuration;
- service health and restart policies;
- JWT authentication;
- rate limiting and validation;
- structured application logs;
- scheduled jobs;
- automated server / bot / client test suites.

No production domains, tokens, customer data, deployment hosts or internal business procedures are included in this showcase.
